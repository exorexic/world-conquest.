# World Conquest

Многопользовательская браузерная стратегия для телефона и компьютера. В проекте есть лобби, комнаты по коду, серверная синхронизация, до 8 игроков, интерактивная карта мира, ресурсы, найм войск, улучшение экономики и захват стран.

## Требования
- Node.js 18 или новее
- Интернет для загрузки картографических тайлов и границ стран

## Запуск на компьютере
```bash
npm install
npm start
```
Откройте `http://localhost:3000`.

## Игра с друзьями
Для игры через интернет сервер нужно разместить на хостинге, поддерживающем Node.js и WebSocket. После размещения все игроки открывают один и тот же HTTPS-адрес. Создайте комнату, отправьте друзьям код и дождитесь подключения. Для начала сетевого матча требуется минимум 2 игрока; максимум — 8.

Для локальной проверки на одном компьютере можно открыть сайт в нескольких вкладках. Чтобы тестировать с телефона в одной Wi-Fi сети, откройте `http://IP-АДРЕС-КОМПЬЮТЕРА:3000`.

## Размещение
Подойдёт любой хостинг Node.js, который поддерживает постоянный процесс и WebSocket:
1. Загрузите содержимое репозитория.
2. Установите Node.js 18+.
3. Выполните `npm install`.
4. Запустите `npm start` (порт берётся из переменной окружения `PORT`).
5. Включите HTTPS на стороне хостинга.

## Управление
- Нажатие на страну — выбрать её.
- «Нанять 10 войск» — потратить 25 ресурсов.
- «Улучшить экономику» — потратить 40 ресурсов, чтобы увеличить доход.
- «Атаковать выбранную страну» — потратить 15 ресурсов; для захвата нужно иметь больше войск, чем защитник с запасом.
- Доход и армия пополняются каждые 5 секунд.

## Важные ограничения текущей версии
Это полноценная запускаемая основа игры, но не коммерческий релиз: нет сохранений между перезапусками, дипломатии, тумана войны, сложного перемещения армий, рейтингов и античита. В сетевой версии нужна постоянно работающая серверная копия; само скачивание ZIP не создаёт публичный сервер автоматически. Карта использует внешние данные и тайлы, поэтому для неё нужен интернет.
